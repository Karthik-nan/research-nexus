# 🚀 Open Research Nexus

> A collaborative research platform built with Spring Boot that enables teams to manage projects, share research documents, and collaborate through structured discussions.

---

## 🧠 What this project does

Open Research Nexus transforms simple document storage into a **team collaboration system** where users can:

- Create and manage research projects
- Upload and organize research documents
- Collaborate using real-time-style comment discussions (backend-based)
- Work together in structured project teams

---

## ✨ Key Features

### 👤 User & Role System
- Multiple users per project
- Role-based access: **OWNER / MEMBER**

### 📁 Project Management
- Create research projects
- Assign team members
- Organize work in structured spaces

### 📄 Research Documents
- Upload and manage documents
- Associate documents with projects

### 💬 Collaboration System
- Add comments on documents
- View document-level discussions
- Enable team communication inside backend
